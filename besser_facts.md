# BESSER core facts

## Name

BESSER stands for **BEtter Smart Software fastER**.
It is an open-source intelligent low-code platform developed at LIST (Luxembourg Institute of Science
and Technology) under an FNR PEARL Chair led by Jordi Cabot.

## B-UML

B-UML stands for **BESSER's Universal Modeling Language** — NOT "BESSER Unified Modeling Language".
B-UML is BESSER's core modeling language for describing software systems (class diagrams, state
machines, object diagrams, deployment specifications, and more).

## LLM support

BESSER is **LLM-agnostic** — it supports local and hosted language models and allows swapping
providers without rewriting agent logic. There is no vendor lock-in to any single provider.
It does not exclusively support OpenAI or GPT models. Users configure which LLM to use
through the Agent Configuration panel in the BESSER editor.
For specific model availability, refer to https://besser-pearl.org/features/agentic-framework/.
